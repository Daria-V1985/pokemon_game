# 📦 Локальная игра Pokemon Clicker

Современный и масштабируемый веб-интерфейс, разработанный на экосистеме **Vue 3** с использованием **TypeScript** и строгой архитектуры компонентов.

## 🚀 Стек технологий
* **Frontend:** Vue 3 (Composition API), TypeScript
* **State Management:** Pinia
* **Routing:** Vue Router
* **Build Tool:** Vite
* **Styles:** SCSS / БЭМ-архитектура

## 🛠️ Что сделано:
1. **Строгая типизация (TypeScript):** Спроектированы и внедрены интерфейсы (`interfaces`) и типы (`types`) для безопасной работы с данными, исключены типы `any`, что минимизировало ошибки компиляции.
2. **Оптимизация состояния (Pinia):** Реализовано централизованное управление данными с модульной структурой сторов.
3. **Компонентный подход:** Интерфейс декомпозирован на независимые, переиспользуемые UI-компоненты.
4. **Адаптивность:** Сверстана полностью отзывчивая и кроссбраузерная сетка с использованием Flexbox/Grid и методологии БЭМ.

## 🏁 Как запустить проект локально:
```bash
# Клонировать репозиторий
git clone [ссылка_на_твой_репозиторий]

# Установить зависимости
npm install

# Запустить локальный сервер для разработки
npm run dev
```
